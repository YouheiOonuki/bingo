How to use the Bingo Caller

Big-screen tips, printable bingo cards, checking winners, FAQ

日本語

What this page covers: running a game on a projector or TV, printing numbered cards, and checking winners.

How to use the bingo caller

  1. Print cards: on the card page, enter how many and press Print.
  2. Draw: press Draw, Space or Enter. Press again during the drum roll to show the number at once.
  3. Check a winner: enter the card's No. under "Check a card by number".
  4. Wrap up: "Show a summary" lists prizes, winners and the draw order to copy.
Prizes, undo and starting over
  • Enter prizes under "Prize order" in the order you give them. The draw screen shows the next prize, and a winning card check offers "Give this player the next prize".
  • "Undo last" removes the last number. "Start over" in Draw settings clears the drawn numbers and winners.
  • No number is drawn twice. "Numbers per draw" draws 2–5 at a time.

Projector and TV tips

Full screen (F key) shows only the draw area, with the largest numbers. Press Esc or "Exit full screen" to leave.

Display, sound and voice
  • On a laptop, set the projector to "Duplicate" so it shows the same screen as yours.
  • On iPhone, Full screen fills the browser window instead.
  • Sound (M) and Voice (V) switch with the buttons or keys. Voice calls say "B 12"; untick "Voice says the letter too" for numbers only.
  • Voice uses your device's built-in speech synthesis, so the voice depends on the device. If you hear nothing, check the volume and silent mode.
  • The draw screen shows no ads, so nothing covers the numbers.

Printable bingo cards (free, up to 200) and checking winners

Print 1–200 cards, 4 or 2 per Letter or A4 page. Every card in a set is different and carries a number like No.KR-042. Enter it on the caller to see the completed line and which draw completed it.

Card layout, printing and checking
  • 1–75 cards use the US layout: B 1–15, I 16–30, N 31–45, G 46–60, O 61–75, FREE in the center. 1–50, 1–90 and 1–100 split the range into five equal columns. Set the caller to the same range.
  • Add a title (e.g. Holiday Party 2026) under More settings. The small credit line can be turned off there.
  • If a page does not fit, match the paper under More settings to your printer's paper, and print portrait at 100% (or "Fit to page") with no or default margins.
  • The first two letters of the No. identify the card set; a card from another set is flagged.
  • The draw screen shows how many printed cards have bingo or are one away (cards not handed out are counted too).
  • The same set code makes the same cards on any device. "Copy link to these cards" sends them to a co-host.

How to speed up a large bingo game

  • Draw 2–3 numbers at a time ("Numbers per draw").
  • Shorten the drum roll to Short or Off.
  • Use 1–50 for both the cards and the caller.
  • Estimate first with "How long until the prizes run out?" on the caller.

FAQ

Can I use this bingo caller with store-bought bingo cards?
Yes. For standard 75-ball cards (B 1–15 to O 61–75), set the range to 1–75. Checking winners by card number works only with cards printed here.
Does the bingo caller work offline, without Wi-Fi?
Yes, on a device that has opened it once while online. The caller, card check and card page then open without a connection. Try it in airplane mode the day before.
What happens if I close or reload the page mid-game?
Drawn numbers, prizes and card settings are saved in this browser, so the game continues when you reopen it. Each number is picked and saved before the drum roll, so reloading never redraws it.

Notes and data

  • Card checks use only cards printed here and numbers drawn on this device. The host makes the final call on prizes.
  • Everything is saved in this browser only (localStorage, keys starting with bingo_) and never sent anywhere. Export, import or delete it from the caller or card page.
  • The card link holds only the card settings, after the "#", so it never reaches our server.
How numbers and cards are made
  • Each number is picked with the browser's cryptographic random generator (crypto.getRandomValues), with equal chances among the numbers not yet drawn.
  • Cards are generated from the set code and the card's position, so the same code always gives the same cards.
  • The time estimate plays the whole game 300 times (with your printed set when the player count matches it) and counts the draws until as many cards as prizes have bingo. Real games vary.
  • Sound effects are generated in the browser; no audio files are used. Free, with no account or app install.
